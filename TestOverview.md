


Performance tests contains of

1. Test tracker

Repositories:

https://github.com/Arkiv-Network/test-tracker - backend
https://github.com/Arkiv-Network/test-tracker-front - frontend

The system is currently deployed under https://tracker.arkiv-global.net

Test tracker is a web application that tracks the progress of the tests,
gathers data and provides a user interface to view the results. 

2. Performance tests itself

Repository:

https://github.com/Arkiv-Network/arkiv-tests

It contains sandbox to set up all main components of the system.
